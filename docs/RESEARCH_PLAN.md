# 研究计划与申请展示

研究问题：图像检索、来源约束与未知拒答能否降低艺术作品身份误认？

## 阶段与现状

1. v0.1.2：完成有界工具流程、检索、双图模型复核、视觉解释与追问及依据展示。
2. v0.2：评估已有双图核验，增加来源级事实核对及有条件的工具路由。
3. v0.3：冻结数据和参数，进行消融实验，记录准确率、未知误认、延迟和 API 成本。
4. v0.4：英文展示材料、演示视频和可复现发布；以后独立接入音频指纹与音乐分析。

## 数据拆分

馆藏原图作为检索图库。采集不同设备拍摄、裁剪、亮度变化及倾斜的查询图片；按作品分组划分验证集和测试集，防止同一作品变体跨组。已知查询对应作品必须在检索图库中；未知查询对应作品必须不在图库。区分“近重复检索”与“新照片检索”，分别报告成绩。不要将图库原图直接作为主要测试集。

未知集加入自画作品、非馆藏作品和授权的 AI 生成图；控制个人信息。记录各艺术地区、媒材和类别覆盖，报告西方馆藏偏差。阈值只在验证集选择，测试集只用于最终评估。

## 对照实验

A：视觉模型直接回答（待实现批量评估）。
B：视觉模型 + CLIP 检索（检索代码已实现）。
C：检索 + 来源核验 + 未知判断（完整来源核验待实现）。

固定视觉模型版本、提示词、图像尺寸和测试集；记录所有变更，不能用不同版本成绩直接归因于检索模块。

## 指标

已知作品 Top-1 / Top-5；未知作品误认率；回答覆盖率与选择性准确率；引用是否支持对应陈述；人工视觉解读评分；端到端延迟和实际计费成本。识别作者与识别作品分别统计，不能以作者正确替代作品正确。

内涵评分使用明确量表：贴合画面、事实正确、来源充分、是否区分推测。至少两名独立评分者时报告一致性；没有专家评分时明确这一局限。不要把大模型自评分直接写成客观真实性。

## GitHub 与申请

展示系统架构、你实际完成的模块、真实实验表格、失败案例和改进过程。说明模型及资料来源；不宣称训练了预训练 CLIP 或视觉大模型。保留有效开发记录。作品集文字在实验完成后写入实际成绩。
