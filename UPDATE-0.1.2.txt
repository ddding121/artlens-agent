ArtLens 0.1.2 更新说明

1. 在运行服务的终端按 Ctrl+C。
2. 备份当前项目。将压缩包内容合并到项目根目录，替换同名文件。
3. 保留 .env、.venv 和 data；补丁没有包含它们。无需安装新依赖或重新建索引。
4. 在项目根目录启动：
.venv\Scripts\python -m uvicorn artlens.main:app --host 127.0.0.1 --port 8000
5. 浏览器 Ctrl+F5 强制刷新；/api/health 的 version 应为 0.1.2。
6. 上传图片，检查标题、段落、核验依据和耗时；继续提问。
7. 确认后 git add .、git commit、git push 即可提交。

改动：安全文本排版，核验依据/差异/相似度领先幅度、真实等待和处理耗时；讲解失败不会覆盖已核验作品信息；中英文 README 更新。
验证：16 项 Python 测试通过，JavaScript 语法和文本解析检查通过。未重新进行真实 API 调用或浏览器视觉测试；不宣称识别准确率提高。
